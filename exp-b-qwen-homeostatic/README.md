# exp-b-qwen-homeostatic — Stage B: injecting homeostasis into a language model

**[English](README.en.md)** | 中文

## 目标

阶段 A 验证了范式（小 Transformer、唯一回报 = 内稳态缺口缩减，六组对照成立）。
阶段 B 的问题更进一步：

> **一个语言模型能否"具身"一个内稳态策略？它的行为是否被内感受调制？**

如果 Qwen-0.5B 在学会"活下去"的同时，行为随身体状态（能量/完整度）改变
——饿时觅食、饱时无视——那么"新物种大模型"的范式就跨过了第二级台阶：
不是背下策略，而是把内稳态判断装进了语言表征里。

## 方法（v1，可证伪）

```
exp-a 课程组策略（教师，12×12，satiated=0 / far=1.00）
        │ 轨迹回放
        ▼
文本观测 → 动作    SFT 数据集（约 2 万条）
        │ QLoRA（4bit，RTX 3050 4GB）
        ▼
Qwen2.5-0.5B-Instruct（学生）
        │ 行为探针
        ▼
1. 教师一致率 —— 学没学会
2. 存活率 —— 能不能活
3. 内感受调制 ★ —— 同样视野、不同能量状态，动作是否改变
   （这是核心探针：拟合策略 vs 装入内稳态判断的分水岭）
```

诚实边界：SFT 只证明"可注入"，不证明"涌现"。若内感受调制成立，
后续用 DPO（内稳态偏好对）与 RL（环境回报直接进策略）检验更深层的注入。

## 结果（v1）——负结果，诚实记录

| 探针 | 结果 | 标准 | 判定 |
|---|---|---|---|
| agreement 一致率 | **0.485**（随机 ≈ 0.2，非法率 0） | > 0.7 | ✗ |
| survival 存活率 | **0.00**（平均 77.7 步/局，非法率 0） | 显著高于随机 | ✗ |
| modulation_gap ★ | **0.00**（饥饿/饱腹朝食物均为 0%） | > 0.5 | ✗ |

**诊断**：贪心解码在 60 个构造状态（食物右侧 3 格、饥饿/饱腹交替）下
100% 输出 `down`——策略坍缩为单一动作。而数据集中教师动作分布为
rest 50% / right 15% / left 14% / up 11% / down 10%：坍缩到的甚至不是
多数类，说明 1 epoch 只完成了"输出一个合法动作词"的**格式学习**，
没有完成观测→动作的**策略绑定**。

**仍然有意义的信号**：非法输出率 0（格式学会了）；一致率 0.485 显著
高于随机 0.2（部分策略信号存在，但不足以支撑存活）。

## v2 计划

1. 数据扩到 200 局（约 7 万条），训练 2–3 epochs
2. 动作分层平衡采样（rest 占 50% 的类不平衡需要处理，或对 rest 下采样）
3. 训练中监控逐动作的预测分布，检测坍缩并早停
4. 扩大 LoRA 覆盖（加入 MLP 层）或增大 r
5. 判读逻辑不变：若 v2 达成一致率 + 存活但 modulation_gap 仍为 0，
   则恰好印证"拟合策略 ≠ 装入内稳态判断"的分水岭假设，升级到
   DPO（内稳态偏好对）

## v2 结果（2026-10-10）——也是负结果，但验证了路线天花板

| 探针 | 结果 | 标准 | 判定 |
|---|---|---|---|
| agreement 一致率 | **0.585**（非法率 0） | > 0.7 | △ 进步但未达标 |
| survival 存活率 | **0.00**（平均 110.6 步/局） | 显著高于随机 | ✗ |
| modulation_gap ★ | **-1.00**（饥饿朝食物 0% / 饱腹朝食物 100%） | > 0.5 | ✗ **反向** |

**v2 配方**：200 局 / 70,300 条 SFT 数据 + 动作分层平衡（rest cap 11867）+ 2 epoch +
训练中逐动作分布监控（200 步一查，top 超过 0.6 报警；实际 top 0.31–0.34 始终健康，
**未坍缩**——验证了监控机制有效）。

**关键诊断**：v2 跨过了 v1 没过的两道坎——
- v1 坍缩为单一动作（`down` × 100%）；v2 分布健康（top 0.33）
- v1 调制 gap=0（无调制）；v2 调制 gap=-1.0（**建立了调制，但方向反了**）

这是 SFT 路线的天花板：**纯行为克隆可以学到动作分布与"内感受→行动"的弱关联，
但无法学到因果方向**。模型在 200 局数据中把"饿"+"left"的少数组合过度记忆化，
导致反向调制。

## 结论与下一步

**SFT 路线已被推到天花板**（v1 坍缩 → v2 反向调制）。要再向前一步，
必须让梯度来自**内稳态后果**（活/死），而非来自行为克隆：

- **DPO**：构造"饥饿时正确去食物" vs "饥饿时错走"的内稳态偏好对，让模型
  直接学到内感受→正确动作的因果
- **PPO/RL**：环境回报（Δ能量、存活步数）直接进策略，绕过行为克隆

## v3：DPO（2026-10-15 建成并跑完训练）

v2 之后启用 DPO。偏好对**不用教师标签**，而用环境真实后果的同状态穷举对比。

### 配方（与用户确认的三项决策）

| 决策 | 选择 |
|---|---|
| 偏好对来源 | 同状态穷举对比：每状态枚举 5 动作各走一步，按内稳态后果排序 |
| 起点 | v2 LoRA 同时作 π_θ 与 π_ref（`disable_adapter` 复用底座，显存 1.2GB） |
| β | 0.1（TRL 默认量级） |

实现：`homeo_lm.gen_dpo_data` / `homeo_lm.dpo`（手写 DPO 损失，零新增依赖；
只算 assistant 段 logprob；复用 SFT 的坍缩监控）。

### 三个标签级陷阱（冒烟测试逐个抓出并修复）

裸的一步对比在内稳态环境里会产出**错误标签**——这是 v3 最关键的经验：

1. **稀疏奖励陷阱**：食物 3 格远时，朝食物走与乱走的一步回报完全相同
   （都是移动成本 -0.015），而 `rest` 成本最低（-0.005）永远最优 →
   裸对比会训出"永远休息"的坍缩。
   **修复**：势函数整形（PBRS）——`shaped = r + w·[φ(s') - φ(s)]`，
   `φ = -dist(食物)` 由饥饿门控、`+dist(危险)` 由受伤门控。
   PBRS 不改变最优策略，且**内感受调制直接内建于门控**。

2. **进食重生陷阱**：吃到食物后食物在别处重生，`φ(s')` 用"重生后的远食物"
   会算出大负整形，淹没 +0.33 的真实进食收益。
   **修复**：进食步跳过整形（裸回报已是强信号）。

3. **视野不连续陷阱**：把"可见性"直接写进 `φ`，食物在视野边缘时向外走一步
   会让它"离开视野"、φ 跳回 0，反而拿到**正**整形。
   **修复**：门控在采样状态一次性判定；同一状态的 5 个反事实用连续的全知距离。

修复后标签全部验证正确：饥饿+食物在右 3 格 → `right`；饱腹 → `rest`
（v2 反向调制的解药）；受伤+邻危险 → 拒绝走进危险；饥饿+邻食物 → 吃。

### 训练结果

4002 对（教师/随机轨迹各半）× 2 epoch = 500 优化步：

| 指标 | 冒烟（200 对） | 正式（500 步） |
|---|---|---|
| loss | 0.52 | **0.12** |
| margin（策略偏向 chosen 的程度） | +0.44 | **+4.23** |
| acc（margin > 0 的比例） | 0.82 | **0.97** |
| 坍缩监控 top | 0.33 | **0.41**（健康） |

margin 从 +0.44 涨到 +4.23：策略已强烈偏向"内稳态更优"的动作——
DPO 回路本身工作正常。

## RSI Phase 0：测量加速 + 控制器骨架（2026-10-25）

完整设计见 [`docs/RSI-PLAN.md`](../../docs/RSI-PLAN.md)。已落地的部分：

### 探针加速（RSI 的前提：测量必须够快）

原来每个动作都走 `model.generate(max_new_tokens=4)`——**一次决策 4 次前向、
逐条串行**。改成**批量首 token 分类**：动作只有一个词，5 个动作词首 token
互不相同（`action_token_ids` 断言），所以"贪心解码一个动作"≡"5 个动作首
token 上取 argmax"，批内**一次前向**出所有决策。存活探针 20 局并行推进。

- 新增 `homeo_lm.acthead`（探针与 PPO 共用的行动头）：`act_batch`、
  `greedy_with_legality`、`batch_logprobs`
- **合法率信号保住了**：把决策限制在 5 个 token 上会让模型"永远合法"，
  所以同时看**全词表 argmax**——落在 5 个动作 token 之外即判非法
- 等价性可实测：`--verify-batching N` 对比批量路径与逐条 generate 的决策
  一致率（< 0.99 则报 `BATCHING MISMATCH`，不得使用快路径）

### `homeo_lm.rsi`（控制器骨架：只测量记账，不自动改）

1. **种子三分** train / select / holdout（留出集冻结，不许对着同一套题练）
2. **探针锁**：探针配置哈希进账本；哈希变了本轮采纳作废
3. **显著性判定**：Δ 的 bootstrap 95% CI 整体 > 0 才算数，不是"看着涨了"
4. **演进账本** `runs/rsi_ledger.jsonl`：每行记 `(tag, parent, change,
   metrics, probe_hash, guardrails)`，可回溯可回滚
5. **守卫**（本版只报告，不自动处置）：非法率超阈、调制 gap < 0（v2 失败模式）

用法：`py -3.12 -m homeo_lm.rsi --ckpt runs/dpo-v3 --tag baseline-A`

### L0 自适应调参（2026-10-25，代码就绪）

`homeo_lm.rsi_l0` + `rsi.py --cycle`：**默认 dry-run**，只输出"下一步试
什么"和对应训练命令，不执行训练（一次试验要真跑训练 + 全套探针）。

| 部件 | 行为 |
|---|---|
| `KNOBS` | 5 个有界旋钮：`shape_w` / `gate_margin` / `teacher_mix` / `entropy_coef` / `curriculum` |
| `FORBIDDEN_KEYS` | 内稳态目标、环境物理、探针、门控自身——**结构性拒绝，不看指标** |
| `ucb_propose` | UCB1：先试未试过的臂，再按"均值 + c·√(ln N/n)"挑 |
| `Budget` | 每周期试验封顶；连续失败 → 熔断，交给人 |
| `oscillating` | 锯齿检测：同一旋钮来回翻转 = 在噪声里打转，停下 |
| `decide` | 三态：守卫失败/显著变差 → **回滚**；显著变好 → 采纳；否则拒绝 |

用法：`py -3.12 -m homeo_lm.rsi --cycle --out runs/rsi_ledger.jsonl`

### L1 自产训练信号（2026-10-25，代码就绪）

L0 调旋钮，**L1 调数据本身**：让学生自己走进环境，在它**当前会犯错的
状态**上做穷举对比——偏好对长在错误发生的地方，分布随策略一起移动
（iterated DPO 与"一次性 DPO"的区别）。

| 部件 | 说明 |
|---|---|
| `gen_dpo_data --policy <适配器> --policy-frac 0.34` | 第三条数据来源：**学生自己的 on-policy 轨迹**；`PolicyDriver` 用 acthead **采样**驱动（不贪心——贪心会把轨迹压到几条确定性路线上，覆盖反而变窄） |
| `homeo_lm.selftrain` | 一轮 = 生成 → 训练 → 多次独立测量 → 判定 → 记账；**采纳**才推进 `current`，否则保留 parent。默认 dry-run |
| `probe --seed-offset` | 显著性判定需要多个独立取样（同一 offset 可复现） |
| `ppo --probe-every N` | 训练中定期插轻量调制探针（模型已在内存，几乎免费），轨迹写 `probe_trace.json` |

**关键工程决策**：L1 每一步都用**子进程**跑，不在同一进程里叠模型——
生成要载教师、训练要载策略+参考、测量要载学生，两个 0.5B 模型同进程在这台
4GB 机器上必炸。

用法：`py -3.12 -m homeo_lm.selftrain --start runs/dpo-v3 --rounds 3`（加 `--run` 才真跑）

## v4 路线：PPO（已实现，未训练）

`homeo_lm.ppo` —— 让环境回报**直入策略**，彻底绕开行为克隆：

    rollout：学生自己在 TextEnv 里玩 → 拿内稳态回报
    update ：PPO-clip 更新 LoRA，高回报动作词的 token 概率上升

| 设计 | 选择 | 理由 |
|---|---|---|
| 动作空间 | 5 个动作词的**首 token**，logits 在这 5 个上重归一化 | 离散动作集上的 RL；熵与采样可控 |
| 优势估计 | 整批回报标准化（无 critic） | 4GB 显存不再塞价值网络；方差高但单模型可训 |
| 奖励整形 | 复用 DPO 的 PBRS（同一套门控/进食步跳过） | 内稳态回报太稀疏，裸用学不动 |
| KL 惩罚 | 不做（省一份参考模型） | 靠 entropy bonus + 小 lr 稳定 |

训练中输出：回报、loss、熵、clip 比例、**存活率/平均回合长度**、逐动作分布
（top > 0.9 报坍缩）。支持 `--resume` 与定期快照，与 SFT/DPO 同一套约定。

用法：`py -3.12 -m homeo_lm.ppo --ckpt runs/dpo-v3 --out runs/ppo-v4`

## 探针读数扩展：`modulation-sweep`

单个 gap 只给一个差值；`--only modulation-sweep` 扫一条能量梯度
（0.2→1.0），给出**剂量-反应曲线**，可区分三种失败模式：

| 曲线形状 | 判定 |
|---|---|
| 全程平 | 无调制 |
| 单调下降 | 反向调制（v2 正是如此） |
| **单调上升** | **正确调制——越饿越想找食物** |

用法：`py -3.12 -m homeo_lm.probe --ckpt <适配器> --only modulation-sweep`
- **两者都需要学生能跑环境**（已实现：`TextEnv` 可 0.5B 跑通）

## 判读标准

1. `agreement` > 0.7 —— 动作分布与教师基本一致（学到了策略）
2. `survival` 显著高于随机基线 —— 能活
3. **`modulation_gap` > 0.5** —— 低能量与饱腹状态下动作分布显著不同
   （内稳态判断被装入语言模型，而非只背了视觉→动作映射）
