# exp-a-homeostatic-rl —— 阶段 A：新物种大模型范式验证

## 目标陈述：给它最基本的意识，让它自己生长

本项目的路线不是"制造"智能，而是"种植"生命性：

> **我们不写意识，我们放置生命的最小条件，然后让它自己长。**

放置四样东西（没有一样叫意识）：

1. **内稳态目标** —— 它"要活"，缺口就是痛苦（动机从哪来）
2. **内感受** —— 它能感觉到自己饿了、伤了（自我从哪来）
3. **预测能力** —— 它在世界里预期下一步（理解从哪来）
4. **有压力的世界** —— 稀缺、危险、必须取舍（生长的驱动力）

生长的机制是**涌现而非灌输**：我们不教"看到食物要追"，
只让食物从多变少；定向觅食、饥饱调制（饱腹接近率 0）、危险回避
都是压力与目标共同作用下自己长出来的行为。课程学习的工程含义
正在于此——**不设计技能，设计发育环境**（食物丰瘠 = 童年营养，
退火曲线 = 成长日程）。

诚实边界：园丁不是上帝。我们仍然决定压力的形状（奖励结构）、
发育的日程（课程）、世界的样貌（环境）。设计压力就是设计它会长
成什么——因此每次实验必须保留消融与对照（我们放的哪颗种子
长出了哪根枝），且每个能力都要测**迁移**（换环境后判断是否
仍成立——只在训练环境里灵光的不叫判断，叫拟合）。

终极取向：**以世界为出发点的自主判断逻辑**（可测量、可证伪），
而非"意识"本身（不可验收）。意识若出现，只能是这个系统复杂化
后的涌现观察对象——我们记录，但不宣称。

分层进度：L1 内在目的（✅ 已达成）→ L2 世界出发的自主判断
（当前主攻：放大实验 + 迁移评测）→ L3 意识样现象（只观察，
不验收）。

## 核心假设

一个模型**不带任何人工任务奖励**、只以内稳态缺口缩减为回报训练，
会自发涌现目标定向行为（觅食、避险、休息权衡），且其世界模型
（预测误差）提供内生的好奇驱动。这是"新物种"范式的最小可证伪实验。

| | 常规 RL / Agent | 本实验 |
|---|---|---|
| 回报来源 | 人工设计（得分/偏好） | 内稳态缺口缩减（M12 思想） |
| 任务 | 外部给定 | 无外部任务，生存即任务 |
| 世界模型 | 可选模块 | 内生辅助损失 + 内在奖励 |
| 死亡 | 回合结束 | 存在性惩罚（-3） |

## 结构

- `homeo_rl.drives` —— 内稳态缺口与奖励（移植自 M12 cog-drives）
- `homeo_rl.env` —— 内稳态网格世界（能量代谢 / 食物 / 危险 / 休息权衡）
- `homeo_rl.model` —— Transformer 主干 + actor / critic / 世界模型三头
- `homeo_rl.train` —— PPO + 预测误差内在奖励
- `homeo_rl.evaluate` —— 行为探针（存活 / 觅食 / 随机基线对比）

## 用法

```powershell
pip install -e ".[dev]"
pytest                                   # 单元测试
python -m homeo_rl.train --updates 500 --out runs/base
python -m homeo_rl.evaluate --ckpt runs/base/checkpoint.pt
```

## 判读标准（什么算"范式成立"）

1. `survival` 随 update 上升并趋近 1（学会不死）
2. `energy` 收敛到设定点 0.8 附近（既不饿死也不贪吃——过量进食无回报）
3. `pe_ema` 持续下降（世界模型越来越准 = "理解"了环境）
4. `foraging.trained.success_rate` 显著高于 `random_baseline`（有目标的行为）

## 与 24 模块认知架构的关系

阶段 A 验证的是**训练目标**（内稳态 + 预测误差），不是模块架构。
范式成立后：阶段 B 将其注入开源底座（Qwen/Llama 后训练），
已有的 M06/M10/M12/M15 等模块作为评测探针与课程生成器复用。

## 第一轮实验结果（2026-09-20，各 500 updates / 512k 步 / CPU 12min）

| 指标 | 充裕组（8 食物） | 稀缺组（2 食物） |
|---|---|---|
| 存活率（训练曲线） | 0.80 | 0.60 |
| 存活率（贪心评测） | 0.65 | 0.45 |
| 完整性稳态（评测终值） | 0.91（设定点 0.9） | 0.68 |
| 预测误差 pe_ema | 0.0117 → 0.0071 | 0.0117 → 0.0067 |
| 觅食探针（食物视野外 4 格） | 0/50 | 0/50 |

### 核心发现

1. **定向觅食在稀缺组涌现**（方向探针，食物可见于 ±3 格内）：
   食物在任何方向 → 20/20 朝食物移动；能量已到设定点 → 20/20 无视食物。
   **行为被内稳态状态调制**——"饿了才觅食"，M12 主张的第一个正证据。
2. **稀缺性压力是定向性的必要条件**：充裕组只演化出刻板巡逻路线
   （存活 0.80 全靠巡游碰食，食物可见时 20/20 背向食物）。
3. 危险回避同样涌现（危险在侧 → 20/20 反向避让）。
4. **未解决**：视野外搜索。低能量无可见食物时执行固定"回"字扫描，
   不是自适应探索；起手能量 0.3 只够 20 步，常饿死在搜索途中。

### 下一步（exp-a 迭代方向）

- 课程学习：食物密度从充裕退火到稀缺（先学会接近，再学搜索）✅ 已验证有效（见下）
- 探索增强：熵系数调度 / 预测误差内在奖励权重提高（进行中）
- 视野外搜索：记忆（到过的格子）、或更长的能量缓冲
- 对照消融：去掉世界模型辅助损失（进行中）

## 第二轮实验：课程组结果（2026-09-21）

训练配置同稀缺组（终局 2 食物），唯一区别：食物密度 8→2 线性退火。

| 探针 | 课程组 | 稀缺组 | 随机基线 |
|---|---|---|---|
| 追击 near_visible（食物 2 格可见） | **1.00**（4.4 步） | — | 0.26 |
| 搜索 far_search（食物 4 格不可见） | **1.00**（14.8 步） | 0.00 | 0.10 |
| 定向接近（上/下/左） | 1.00 | 1.00 | — |
| 饱腹接近（不应觅食时） | **0.00** ✅ | 0.00 | — |
| 危险进入率 | **0.00** ✅ | 0.00 | — |
| 存活率（贪心评测） | 0.50 | 0.45 | — |

**结论：视野外搜索问题被课程学习解决**——10 倍于随机基线的搜索成功率。
第一轮未解问题闭环。已知瑕疵：食物在视野边缘（3 格）时存在系统性绕行偏移。

探索组中期信号（200/500 轮）：存活率 0.0——内在奖励权重 0.1 过强，
好奇信号淹没了内稳态信号，本身是有价值的负结果。
